# praktikum-vcs-pti
Latihan Version Control System mahasiswa PTI.
Proyek ini merupakan pembuatan portofolio pribadi berbasis website yang digunakan untuk memperkenalkan diri, menampilkan informasi pribadi, riwayat pendidikan, keterampilan, serta hasil karya atau proyek yang telah dibuat. Website ini dirancang dengan tampilan sederhana, menarik, dan mudah digunakan.
